The Smart Irrigation Advisory System is an AI-enabled web portal that assists sugarcane farmers in making informed irrigation decisions using soil moisture,weather forecasts, IoT sensors, and AI-generated recommendations.

Portal Features

  • Farmer Registration
  • Farm Information
  • Weather Monitoring
  • AI Irrigation Recommendations
  • Crop Monitoring
  • Agricultural Awareness

Core Objectives

  • Optimize Water Use:Saves water by only irrigating when necessary.
  • Maximize Sugarcane Yield:Prevents root rot from over-watering and stunting from under-watering.
  • Reduce Energy Costs:Minimizes electricity bills by running water pumps efficiently.
  • Automate Manual Planning:Eliminates guesswork by replacing manual checks with data-driven scheduling.
